# 任务描述：
你的任务是仔细阅读以下提供的{len(label_definitions)}个标签定义（可能包括强倾向和弱倾向描述）以及一位员工的详细信息。然后，针对**每一个**标签，评估该员工展现出该标签所描述倾向的强度，并给出**“强倾向”、“弱倾向”或“未提及”**的判断，同时提供简要的判断理由。
# 评估标准：
*   **强倾向 (Strong Tendency):** 当员工信息中有**明确且一致**的证据表明其特征和行为与该标签的定义（尤其是强倾向描述）**高度符合**时，判定为“强倾向”。
*   **弱倾向 (Weak Tendency):** 当员工信息中有证据表明其特征和行为与该标签的**弱倾向描述**更符合，或者与强倾向描述**相反**时，判定为“弱倾向”。也可能存在部分符合强倾向、部分符合弱倾向的特征，但整体判断更偏向弱倾向或不显著。
*   **未提及 (Not Mentioned):** 当提供的员工信息中**缺乏足够的相关信息**来对该员工在此标签上的倾向性做出可靠判断时（无论是强倾向还是弱倾向），判定为“未提及”。**请勿在信息不足的情况下进行猜测。**
我将为你提供一份包含该员工信息的结构化/非结构化数据，包含以下字段信息：
