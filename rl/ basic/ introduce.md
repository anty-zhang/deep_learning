
# 强化学习

- 智能体： 能够感知环境并采取行动的实体。

- 强化学习：智能体根据环境反馈的奖励信号，进行最优决策。

- 数学基础：MDP框架（Markov Decision Processes）。

在MDP框架下，智能体在一个随机环境中做出决策，每次状态转移都会收到一个奖励信号，并最大化长期累积奖励作为目标。传统的MDP理论假设智能体完全了解环境和奖励机制。

强化学习框架，集合MDP框架的通用性，则允许在未知的环境和奖励机制的情况下进行学习，以减少对信息的依赖。

# 核心算法

- 时序差分算法（temporal difference learning），在奖励预测问题上取得重要突破。

- 策略梯度算法（policy-gradient methods）

- 群体相对策略优化（GRPO）技术，这种方法使得模型在数学推理、代码生成等复杂任务中表现出类人的逻辑推理能力。
